# Grade 6 Tech · Canva

Classroom website for a Grade 6 Technology unit on Canva Education.

Live site: https://scaemrfung.github.io/Grade-6-Canva/

Thirteen click-by-click lessons, four hand-in projects, and a print-ready poster. Teacher and student views, stampable lessons, and checkable steps.

Visual style matches the Grade 5 Health site: cream paper, cocoa brown, Newsreader headlines, Figtree body.
