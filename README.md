# Grade 6 Tech • Learn to Use & Create with Canva

A ready-to-teach **Grade 6 Technology** unit website.

Students learn how to use Canva Education and create original work, from account setup through a print-ready final poster.

## Live site

- Repository: https://github.com/scaemrfung/Grade-6-Canva
- GitHub Pages (if enabled): https://scaemrfung.github.io/Grade-6-Canva/

To turn on the live website:
1. Open the repo on GitHub
2. Go to **Settings → Pages**
3. Under **Source**, choose **Deploy from a branch**
4. Select **main** and **/ (root)**
5. Save

## What’s included

- **Lesson 0:** Create a Canva Education account (teachers + students)
- **Lessons 1–12:** Step-by-step Canva skills
- **4 hand-in projects** with rubrics
- **Final project:** print-ready showcase poster
- Teacher Hub and classroom tips

## How to use in class

Open `index.html` in a browser, or share the GitHub Pages link with students and teachers.
