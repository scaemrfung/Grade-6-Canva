Classroom

How the block works

Teach from this page. Students design in Canva Education with the lesson open beside it. End every class with a saved PNG and a stamp.

Before day one

  1. Complete Lesson 0 and wait for Canva Education verification if it is not instant.
  2. Create a class and write the join code on the board.
  3. Put a blank name-card template in the class folder for Lesson 1.
  4. Decide where students hand in files (Classroom, Teams, or a shared drive).

On student screens

  1. Open this website and open the lesson for today. The numbered cards are the only list they need.
  2. Open Canva in another tab. Work through the cards in order and tap each one when it is done.
  3. At the end, tick every box under Done when, then download a PNG.

During the 30 minutes

  1. Warm-up (5). Students log in and open yesterday’s design or Make a copy of a starter.
  2. Teach (8). Model one skill on the projector using the Teacher demo cards. Pause after each click.
  3. Make (12). Students follow the numbered student steps. Walk the room. Point to Watch out for if you see the same mistake twice.
  4. Close (5). Download PNG, two volunteers share, stamp the lesson, name tomorrow’s page.

Fast finishers

Every lesson has a Challenge. Use it for extra time, homework, or a hallway display. Do not skip the PNG download to do the challenge.
